How it works

Straight from your phone to your server.

There's no Bosunarr cloud in the middle. The app talks to each service's own API, the same way its web UI does, over whatever route you already use.

  1. 1

    Install

    Download the APK from GitHub. After that, updates arrive in the app itself.

  2. 2

    Connect

    Pick your services, paste a URL and API key, and watch each connection test go green.

  3. 3

    Sail

    Your dashboard fills in straight away. Prefer a test drive? A demo mode is on the way.

Privacy

Your keys never leave your phone.

Bosunarr has no backend and no account system, so there's nobody in the middle to trust, and nothing to breach.

Read the privacy policy arrow_forward
  • smartphone

    Direct connections

    Requests go from your phone to your server, over your LAN, a VPN or your own reverse proxy.

  • encrypted

    Encrypted on device

    API keys and passwords are sealed with AES-256-GCM using a key held in the Android Keystore.

  • no_accounts

    No account, no tracking

    No sign-up, no analytics, no ads. The only other call it makes is an update check to GitHub.

  • policy

    Open source

    Every line is on GitHub under the AGPL-3.0. Read it, build it yourself, improve it.

FAQ

Questions, answered.

Which Android versions are supported?expand_more

Android 10 or newer. Wallpaper-based colour needs Android 12+; on older versions Bosunarr uses its own purple theme.

Is it free?expand_more

Bosunarr is free while it's in early access, with no ads. A Pro tier is planned to support development; details will be shared on GitHub when it's ready. The source code is open under the AGPL-3.0.

How do I install it?expand_more

Download the APK on your phone and open it. Android will ask you to allow installs from your browser or file manager the first time. After that, Bosunarr checks GitHub Releases for new versions and can update itself.

How does it reach my services?expand_more

Your phone connects to each service directly, using the URL and API key (or username and password, for qBittorrent) that you enter. On home Wi-Fi that's a LAN address like http://192.168.1.20:8989; from anywhere else, use a VPN such as Tailscale or WireGuard, or your own reverse proxy with HTTPS.

Do I need to host anything extra?expand_more

No. There's no companion server or cloud account. The app is the whole thing.

Where are my API keys stored?expand_more

Only on your phone, encrypted with AES-256-GCM using a key kept in the Android Keystore. They're only ever sent to the service they belong to.

Can I try it without a server?expand_more

Soon. A demo mode with sample content is on the way, so you can explore every screen before connecting anything.

Is there an iPhone version?expand_more

No. Bosunarr is a native Android app built with Kotlin and Jetpack Compose.

Something's broken or missing. Where do I report it?expand_more

Open an issue on GitHub. Feature ideas are welcome too.
