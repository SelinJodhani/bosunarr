Privacy

Your keys never leave your phone

Bosunarr has no backend. The app talks to your services directly, the same way their own web UIs do, so there's nobody in the middle to trust.

  • smartphone
    Direct connections

    Requests go from your phone to your server — over your LAN, a VPN or your own reverse proxy.

  • encrypted
    Encrypted on device

    API keys and passwords are sealed with AES-256-GCM using a key held in the Android Keystore.

  • no_accounts
    No account, no tracking

    No sign-up, no analytics, no ads. The app doesn't phone home.

  • code
    Open source

    Every line is on GitHub under the AGPL-3.0 licence. Read it, build it, improve it.

FAQ

Questions, answered

Which Android versions are supported? expand_more

Android 10 or newer. Dynamic (wallpaper-based) colour needs Android 12+; on older versions Bosunarr uses its own purple theme.

Is it free? expand_more

Yes — completely free, with no ads, subscriptions or paywalled features. It's open source under the AGPL-3.0 licence.

How do I install it? expand_more

Download the latest APK from GitHub Releases on your phone and open it. Android will ask you to allow installs from your browser or file manager the first time.

How does it reach my services? expand_more

Your phone connects to each service directly using the URL and API key (or username and password, for qBittorrent) that you enter. That works on your home Wi-Fi with a LAN address like http://192.168.1.20:8989, or from anywhere through a VPN such as Tailscale or WireGuard using the server's VPN address. If you already expose services through your own reverse proxy with HTTPS, use those URLs instead.

Do I need to run a server for Bosunarr? expand_more

No. There's nothing extra to host — the app is the whole thing. (There is also an older self-hosted web version, published as a Docker image, if you'd rather use a browser; the Android app is the main focus now.)

Where are my API keys stored? expand_more

Only on your phone, encrypted with AES-256-GCM using a key kept in the Android Keystore. They're never sent anywhere except to the service they belong to.

Is there an iOS version? expand_more

No. Bosunarr is a native Android app built with Kotlin and Jetpack Compose. There is no iPhone or iPad version.

Something's broken or missing — where do I report it? expand_more

Open an issue on GitHub. Pull requests are welcome too.
